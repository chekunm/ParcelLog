# Стан доказів ЛР3

> Актуальний підсумок 30.10: S1/S2 та S3 із керованим входом записані в `systick-s1-20261030/`, `systick-s2-20261030/` і `systick-s3-trigger-20261030/`. S2 має понад 3755 с модельного часу, S3 — 120 фронтів у FLASH і 117 однозначних реакцій; три неоднозначні наведено окремо. `erase_ok=0`, стійкість журналу не доведено. Наведений далі первинний стан — історія пілота, а не актуальна таблиця.

Поточні результати: ARM-збірка, секції ELF/map/su, host functional tests, GCC coverage та Linux ASan/UBSan. Файли build-first/second/third і memory-first є проміжними перевірками; актуальні фінальні значення брати з build.log, memory.log та source-manifest.json після останньої збірки.

`host-scenarios.log` містить **fake_time_ms**, а не виміряні часи MCU. S1 має 2000 вибірок; S2 має 36000 вибірок за 3600000 мс тестового часу, 30 оглядів і 60 PIR-подій. Цей тест триває секунди на хості і не замінює годину роботи S2. S3 перевіряє потік 40 команд, recovery при TX backpressure/RX overflow, відмову/відновлення IMU, заповнення журналу. Таймінги mock-периферії не моделюють реальну flash.

Виконано один власний негативний capability pilot f5c3597ae840dba0. UART323 bytes/65,34 wall seconds; VCD82,49 simulator seconds і один завершений sample. Це не S1/S2/S3. Clock correctness не встановлена, затриманий UART-вивід не є виміром дрейфу. Нова діагностична b8047132268a8f5e поки не запускалась. Таблиця нижче навмисно не містить чисел із host-тестів.

`source-manifest.json` зв'язує банер із вихідними файлами. `seal_build.py` виключає сам build_version.h, але охоплює застосунок, адаптери, Core, linker, flags, diagram, конфіг Wokwi та незмінний manifest HAL. Повний snapshot результатів фіксує ще хеші ELF і тестів у run-manifest.json. Зміна вихідних файлів потребує нової збірки та нового запуску.

CLI Wokwi не налаштований, WOKWI_CLI_TOKEN відсутній. Власний пілот збережено у pilot-f5c3597-01, manifest має raw-хеші й умови. Після нього GUI закрито. Діагностичний план та збірка у diagnostic/. Це організаційний стан локального запуску; технічна підтримка flash у симуляторі ще не перевірена. Фізичної плати немає.
